# Northstar frontend replacement

This archive contains **only the `frontend/` folder**. It does not include or replace `dashboard/` or `Backend/`.

## Replace the frontend safely
1. Back up your existing project `frontend` folder.
2. Extract this ZIP.
3. Copy the extracted `frontend` folder into your project root, replacing the old `frontend` folder.
4. Leave `dashboard/` and `Backend/` unchanged.

## Run
```bash
cd frontend
npm install
npm start
```

## Pages included
- Home, Products, Pricing, About, Support
- Northstar login and signup
- Responsive header/footer and 404 page

The existing auth API configuration and endpoint integrations are retained. The marketing hero uses illustrative sample figures, not live market data. Northstar is a demo/student project, not a brokerage.
